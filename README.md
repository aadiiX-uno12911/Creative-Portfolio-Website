# About the Project

**Akira Kurusova — Portfolio** is a modern, typography-driven front-end project showcasing design work across digital experiences, UI/UX, and content design. 

The site focuses on large editorial-style typography, a minimal color palette, and a clean grid layout that lets the design work speak for itself. It includes sections for **Work**, **About**, **Store**, and a direct **Chat** link, making it easy for potential clients and collaborators to connect.
